# 一字千金 21季 單人賽 練習系統

公視《一字千金 妙筆生花風雲榜》21 季單人賽（A 版）四大單元的個人練習工具。
純前端靜態網頁，開瀏覽器即可用。

線上版：https://mathruffian-dot.github.io/yizi-qianjin-practice/

## 功能

- 去無成字 30 秒（290 題）／四說新語 40 秒（153 題）／成雙成對 30 秒（30 組）／隻字片語 60 秒（對戰電腦）
- 每個單元可選難度：易／中／難；隻字片語可選電腦強度
- 錯題本：答錯自動收集、可專練，連續答對兩次自動移出（存在瀏覽器本機）
- 綜合模擬賽：四關連續出題、合計總分、保留歷次成績
- 米字格手寫作答＋線上辨識（需連網）
- 筆順動畫與描紅測驗

## 檔案

| 檔案 | 內容 |
|---|---|
| `index.html` | 程式 |
| `data.js` | 題庫（去無成字、四說新語、成雙成對、常見成語） |
| `idioms.js` | 成語判定清單，約 3 萬 5 千條；進入隻字片語或四說新語時才載入 |

## 題庫來源與授權

題庫由以下公開資料自動產生，再經人工抽查剔除冷僻、字形有爭議的題目：

- 教育部《重編國語辭典修訂本》、《成語典》開放資料（[國語辭典公眾授權網](https://language.moe.gov.tw/001/Upload/Files/site_content/M0001/respub/index.html)，CC BY-ND 3.0 臺灣）
- 教育部常用國字標準字體表、次常用國字標準字體表（取自 [ButTaiwan/cjktables](https://github.com/ButTaiwan/cjktables)）
- 漢字部件拆解資料 [cjkvi-ids](https://github.com/cjkvi/cjkvi-ids)

答案標準依教育部重編國語辭典修訂本。筆順請以教育部國字標準字體筆順學習網為準。
本站為個人練習工具，與公共電視及《一字千金》節目無關。
